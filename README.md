# CleanerGroupAuctions

A cleaner, faster interface for [MyGroupAuctions.com](https://mygroupauctions.com), the auction site used by aquarium clubs. CGA is a browser extension for Chrome and Firefox (desktop) and Firefox for Android. It takes over MGA pages using your own login and adds search, filters, a watchlist with notes and max bids, simpler selling tools and your own colors. A Classic view switch brings back the original site at any time.

Your data stays in your browser. CGA has no servers and collects nothing.

Made by [@JonoAugustine](https://github.com/JonoAugustine). Not affiliated with MyGroupAuctions or the Raleigh Aquarium Society.
